# Designs

这个目录专门放：

- 后续重构方案
- 局部模块设计提案
- 评测设计
- 成本控制方案

它和现有文档的分工建议是：

- `ARCHITECTURE*.md`：系统总体结构
- `DB_SCHEMA*.md`：数据库设计
- `IMPLEMENTATION_PLAN*.md`：阶段推进计划
- `CURRENT_STATUS.md`：当前代码状态
- `designs/*.md`：下一步准备怎么改、为什么这样改、怎么评估
